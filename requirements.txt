#     CPU, so install the CPU build first and then the rest:
#       python -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
#       python -m pip install -r requirements.txt
#   - Intel Macs: PyTorch no longer publishes wheels for them. Tell the instructor
